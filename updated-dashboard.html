Recommended Principles

Based on "Speed up decisions" in "Decision & approvals"

linear_scale

Hick's Law Optimization

High Reduction

Minimize the number of stimuli to reduce time and errors in decision-making processes.

Why it applies

Decision nodes present 12+ parallel options without hierarchy.

Impact Type

Latency Reduction

expand_more

constructionDesign Actions

  • check_circleCategorize primary vs secondary actions visually
  • check_circleApply progressive disclosure for edge-case data
  • check_circleGroup lab variables under semantic section headers

infoUsage Rules

When to use

During high-speed diagnostic triage where reaction time is critical.

When not to use

In investigative deep-dives requiring all raw data points visible.

biotechLife Sciences Example

Redesigned Gene Sequencing analyzer to hide low-confidence alleles until explicitly requested by the pathologist.

visibility

Von Restorff Effect

Moderate Reduction

Predictably isolate the most important information to ensure it is noticed first.

Why it applies

Critical patient alerts are visually identical to routine status notifications.

expand_more

Design Actions

  • check_circleUse contrasting color for critical alerts vs routine items
  • check_circleAnimate only high-priority status changes

UI Patterns

  • arrow_forwardHighlight badges for critical status table rows
  • arrow_forwardPin urgent action items to the top of the list
memory

Miller's Law Chunking

High Reduction

Break complex datasets into digestible chunks of 5–9 items to reduce working memory strain.

Why it applies

Form sections contain 40+ fields in a single vertical scrolling stack.

expand_more

Design Actions

  • check_circleBreak long forms into themed sections of ≤7 fields
  • check_circleUse whitespace and clear headers to delimit groups

UI Patterns

  • arrow_forwardMulti-step wizard for complex workflows
  • arrow_forwardAccordion panels to hide secondary fields
lightbulb

Recognition Over Recall

High Reduction

Minimize memory load by making objects, actions, and options visible and contextual.

Why it applies

System requires memorization of keyboard shortcuts for common actions.

expand_more

Design Actions

  • check_circleShow contextual tooltips with keyboard shortcut reminders
  • check_circleSurface recently used items in prominent positions

UI Patterns

  • arrow_forwardCommand palette with type-to-search for all actions
  • arrow_forwardInline help text near form fields on focus
