Design Actions
Low Load

Progressive Disclosure

Defers complex features to secondary screens to maintain initial clarity.

  • check_circle Advanced filter systems
  • check_circle Multi-step onboarding
  • check_circle Admin dashboards

warning Discoverability issues; users may never find 'hidden' power features.

Implementation

Use 'Show More' accordions and contextual tooltips.

Constraint

Max 3 layers of nesting before task abandonment peaks.

Moderate Load

Chunking (Miller's Law)

Groups information into manageable units (5-9 items) for working memory.

  • check_circle Form field grouping
  • check_circle Navigation menu structure
  • check_circle Credit card input formatting

warning Over-chunking can lead to fragmented UX and excessive scrolling.

Implementation

Use whitespace and clear section headers to divide data.

Constraint

Optimal chunk size is 4 for high-stress environments.

High Complexity

Hick's Law

States that decision time increases logarithmically with the number of choices.

  • check_circle CTA prioritization
  • check_circle Pricing plan comparison
  • check_circle Emergency shutdown UI

warning Oversimplification can remove necessary nuance for expert users.

Implementation

Highlight "Recommended" choices to reduce analysis paralysis.

Constraint

Avoid more than 5 critical options per viewport.
