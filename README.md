# Cognitive Engine

A visualization project for cognitive engine interfaces with multiple dashboard views.

## Features

- **Full Library View**: Complete library visualization with cognitive engine data
- **Compare Mode**: Side-by-side comparison interface
- **Updated Dashboard**: Modern dashboard with real-time updates

## Files

- `index.html` - Main landing page with full library visualization
- `compare-mode.html` - Comparison mode for analyzing different datasets
- `updated-dashboard.html` - Updated dashboard with enhanced UI

## Getting Started

1. Clone this repository
2. Open any HTML file in your browser to view the visualizations
3. For local development, use a live server extension or run `python3 -m http.server 8000`

## Technology Stack

- HTML5
- Tailwind CSS
- Google Fonts (Manrope, Inter)
- Material Symbols
