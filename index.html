#01

Hick's Law

Low Load 97% match

Decision Making · Choice Architecture

Decision time increases logarithmically with the number of choices. Limit options to accelerate user decisions.

expand_more

constructionDesign Actions

  • check_circleLimit primary actions to 3–5 options per view
  • check_circleGroup secondary actions under an overflow "More" menu
  • check_circleUse progressive disclosure for advanced configuration

layersUI Patterns

  • arrow_forwardDropdown instead of an expanded flat list
  • arrow_forwardStepper wizard for multi-step decisions
  • arrow_forwardTabs to group related action clusters

warningAnti-Patterns to Avoid

  • • Displaying all options simultaneously without visual hierarchy
  • • Assigning equal visual weight to primary and secondary actions
  • • Omitting a clear recommended or default option

biotechLife Science Example

Test ordering redesign: showing "Most Common Panels" first instead of the full catalogue reduced lab technician selection time by 60% in clinical workflows.

Miller's Law

High Load 92% match

Working Memory · Information Density

The average person holds 7 ±2 items in working memory. Chunk content into groups of 5–9 to optimize recall.

expand_more

Design Actions

  • check_circleSegment long forms into thematic sections ≤7 fields
  • check_circleApply whitespace and dividers to create visual chunks

UI Patterns

  • arrow_forwardAccordion panels to group related content

Von Restorff Effect

Low Load 88% match

Visual Attention · Salience Design

Items that stand out from surroundings are more likely to be remembered. Isolate critical elements visually.

expand_more

Design Actions

  • check_circleUse contrasting color for critical alerts vs. routine items
  • check_circleApply subtle animation only to high-priority indicators

UI Patterns

  • arrow_forwardPin-to-top for urgent action items

Motor Efficiency · Input Optimization

Time to reach a target is a function of its size and distance. Make critical interactive elements large and proximate.

Design Actions

UI Patterns

Serial Position Effect

Moderate 79% match

Memory · List Complexity

Items at the beginning and end of a list are remembered better. Place critical actions at primacy and recency positions.

expand_more

Design Actions

  • check_circleSurface primary CTA at top; confirmation/exit at bottom

UI Patterns
