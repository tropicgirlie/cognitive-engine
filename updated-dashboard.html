Hick's Law Optimisation

High Impact

Minimise stimuli to reduce decision time and error rate.

Why it applies

Decision nodes present 12+ parallel options without hierarchy.

Impact type

Latency Reduction

Von Restorff Effect

Moderate Impact

Predictably isolate the most important information to ensure it's noticed first.

Why it applies

Critical patient alerts are visually identical to routine status notifications.

expand_more
Design Actions
  • check_circleUse contrasting colour for critical alerts vs routine items
  • check_circleAnimate only high-priority status changes
UI Patterns
  • arrow_forwardHighlight badges for critical status table rows
  • arrow_forwardPin urgent action items to top of list
memory

Miller's Law Chunking

High Impact

Break complex datasets into digestible chunks of 5–9 items to reduce working memory strain.

Why it applies

Form sections contain 40+ fields in a single vertical scrolling stack.

expand_more
Design Actions
  • check_circleBreak long forms into themed sections of ≤7 fields
  • check_circleUse whitespace and clear headers to delimit groups
UI Patterns
  • arrow_forwardMulti-step wizard for complex workflows
  • arrow_forwardAccordion panels to hide secondary fields
lightbulb

Recognition Over Recall

High Impact

Minimise memory load by making objects, actions, and options visible and contextual.

Why it applies

System requires memorisation of keyboard shortcuts for common actions.

expand_more
Design Actions
  • check_circleShow contextual tooltips with keyboard shortcut reminders
  • check_circleSurface recently used items in prominent positions
UI Patterns
  • arrow_forwardCommand palette with type-to-search for all actions
  • arrow_forwardInline help text near form fields on focus
