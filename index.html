Selected Principle

Miller's Law

"The average person can only keep 7 (plus or minus 2) items in their working memory."

description Description

Organizing content into smaller chunks helps users process, memorize, and recall information more easily. Large datasets should be segmented into manageable logical groups.

Cognitive Impact

85% High

Violating this principle causes immediate user disorientation and loss of current task state.

Suggested Interventions

  • check_circle Implement progressive disclosure for secondary data.
  • check_circle Group related navigation elements into categories of max 5 items.
